## Reading the results

Each visit that calculates, asks for a PDF, books a call or opens WhatsApp is counted with its `source`. In Supabase:

```sql
select source, name, count(*) from events where at > now() - interval '30 days' group by 1, 2 order by 1, 3 desc;
```
